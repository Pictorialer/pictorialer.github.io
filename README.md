# Pictorialer 웹사이트

앱 소개 · 고객 지원 · 개인정보 처리방침 · 이용약관 (영어 / 한국어 / 日本語)

- `index.html` 소개 + 고객 지원(FAQ)
- `privacy.html` 개인정보 처리방침 (스토어 제출용 URL)
- `terms.html` 이용약관 (Google Play 판매자 선언·Apple 심사용 URL)
- 언어: 기본 영어, 상단 버튼으로 전환 (`?lang=ko` 처럼 주소로도 지정 가능)

## 사업자 정보 자리표시
아래 글자를 실제 정보로 바꿔야 함 (모든 html 파일):
`{{BIZ_NAME}}` 상호 · `{{CEO}}` 대표자 · `{{BIZ_NO}}` 사업자등록번호 · `{{ADDRESS}}` 주소 · `{{EMAIL}}` 연락 이메일

## 이미지
`assets/img/` 의 로고·그림·앱 화면은 앱 저장소(bt_remote)의 `tool/icon`, `tool/screenshots` 로 생성한 것.
글꼴 Pacifico: OFL 라이선스 (`assets/fonts/OFL-Pacifico.txt`)
